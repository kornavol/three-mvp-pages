# Параметрическая берёза · итерация 1

Дата: 2026-10-04. Статус: **ожидает оценки пользователя**. Версия приложения остаётся 2.1.1.

## Гипотеза и условия

Прежняя проба переключала два генератора и не решала задачу. Гипотеза: воспроизвести правила взрослой Blender-берёзы процедурно, сохранив три формы листьев и общий механизм роста/ветра. Получить разные структуры по seed без старых оболочек крон. Снимок заменённого кода — `replaced-merged-draft.tar.gz`; старые исходники также оставлены в проекте.

Параметры: высота 4.7, изгиб .35, размах/объём/лист/густота/побеги 1, основные ветви 10, весенняя палитра. Галерея: 240104 + n×7919, n=0…11. Эталон 240104 использует закреплённые взрослые данные; остальные — новую структуру. Ракурс спереди, одинаковые свет и размер окна 1280×720. Галереи автоматически вписывают каждый экземпляр. Пять отметок 0/25/50/75/100% для 248023 и 295537 сняты с кадром по текущей стадии; ролики — фиксированная камера по конечной стадии. Ветер 0, кроме записи 295537 с силой 60%, направлением 45°.

## Художественная самооценка

| Критерий | Результат | Свидетельство и вывод |
|---|---|---|
| Различимый силуэт по seed | выполнено | В `adults-studio.png` различаются расположение крупных ветвей, боковые просветы и наклон верхушек; особенно 271780, 295537 и 311375. |
| Характер берёзы и качество отдельных листьев | выполнено | `compare-248023-studio.png`: свисающие тонкие побеги, отдельные листья и белая кора сохраняют принятый характер. |
| Равномерно убедительное заполнение кроны | не выполнено | Галерея: у части форм выражены пустоты между ярусами; в частности 271780 и 311375. Это ограничение первой пробы, не объявляется принятым стилем. |
| Читаемость на острове | выполнено для взрослого, неясно для раннего | `compare-248023-island.png`: взрослая берёза читается; общий кадр ранних фаз на острове очень мелкий. Это не новая камера игры. |
| Целостность креплений | выполнено на просмотренных кадрах | Пять отметок и кадры раннего роста: видимых оторванных листовых групп нет. Это не исчерпывающая численная проверка всех креплений. |
| Естественность движения | неясно | Просмотрены извлечённые кадры записей, но не выполнена полноценная оценка видео в реальном времени. Между примерно 25–50% крона быстро наполняется, ранняя форма разрежена. |

Качество вариативности улучшено по сравнению с фиксированной моделью. Равномерность плотности кроны и естественность переходов требуют оценки пользователя. Следующую художественную гипотезу до этой оценки не начинаем.

## Проверки

Выполнены: четыре новых теста воспроизводимости, разделения случайных последовательностей, действия параметров, явного импорта; выборочная проверка точных позиций/нормалей/цветов эталона и восстановления взрослого варианта; загрузка страницы, галерея, снимки и записи в браузере. Для публикации выполнены сборка, весь существующий набор тестов (309 клиентских + 9 worker), lint (0 ошибок, 18 прежних предупреждений). Узкая вёрстка 390×844 проверена: горизонтального переполнения нет; это не испытание физического телефона. Исправлена ошибка aspect камеры галереи после сравнения в двух видах, материалы пересняты.

Отложены до принятия: полная матрица крайних параметров/seed, непрерывность и крепления, точность теней ветра, расширенная проверка ресурсов и отмены, контракт полива через изолированного потребителя, измерения физического телефона. Дополнительно проверено сохранение эталонной древесины при смене размера/густоты/палитры листьев; после исправления повторены четыре профильных теста, сборка и lint. Существующие навыки и игра не изменялись. Публикуется только мастерская и материалы, без релиза версии.
