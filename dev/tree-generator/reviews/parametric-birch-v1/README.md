## Гипотеза и условия

Прежняя проба переключала два генератора и не решала задачу. Гипотеза: воспроизвести правила взрослой Blender-берёзы процедурно, сохранив три формы листьев и общий механизм роста/ветра. Получить разные структуры по seed без старых оболочек крон. Снимок заменённого кода — `replaced-merged-draft.tar.gz`; старые исходники также оставлены в проекте.

Параметры: высота 4.7, изгиб .35, размах/объём/лист/густота/побеги 1, основные ветви 10, весенняя палитра. Галерея: 240104 + n×7919, n=0…11. Эталон 240104 использует закреплённые взрослые данные; остальные — новую структуру. Ракурс спереди, одинаковые свет и размер окна 1280×720. Галереи автоматически вписывают каждый экземпляр. Пять отметок 0/25/50/75/100% для 248023 и 295537 сняты с кадром по текущей стадии; ролики — фиксированная камера по конечной стадии. Ветер 0, кроме записи 295537 с силой 60%, направлением 45°.
